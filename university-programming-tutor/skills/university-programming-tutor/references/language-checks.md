# 语言易错点与跨语言比较

用于选择检查方向和避免误导性类比；不是一份完整语言规范。只读取相关小节。涉及版本、求值顺序或标准细节时查适用规范。

## C

- 区分数组对象、指针变量和数组形参；`sizeof` 在这些位置的含义不同。给指针传参不会自动传入数组长度。`a[n]` 对长度为 n 的数组不是合法元素。
- 核对字符串容量、结尾的 `\0`、输入宽度、返回值和格式说明符；例如 `scanf` 的 `%f` 与 `%lf` 接收的指针类型不同。`getchar` 返回值应能表示所有无符号字符值和 EOF。
- 检查未初始化读取、局部对象地址逃逸、重复释放、释放后使用、分配大小与失败处理；`malloc` 大小计算也可能溢出。
- 检查有符号整数溢出、整除截断、符号与无符号混合、移位范围和隐式转换；不要假定 C 的 `int` 必为 32 位。先转宽再运算与先溢出再赋给宽类型不同。
- 对复杂自增表达式分析适用标准的顺序关系；不要给未定义行为安排一个“标准输出”。区分未定义、未指定、实现定义三类情况。
- 审查资源和输入错误时结合题目约束，避免把所有库调用都机械地判为错误。

## C++

- 先核对 C++ 标准，不能直接沿用 C 的全部规则。检查对象生命周期、临时对象、返回局部引用或指针、lambda 捕获及悬空引用。
- 检查容器修改是否使当前迭代器、引用或指针失效；按具体容器及具体操作判断，不能泛称“修改容器一定失效”。区分 `size()`、`capacity()` 和有效元素范围。
- 检查所有权、析构与异常路径；手动资源管理的类需关注复制/移动语义。RAII 和标准容器可作为改进，但课程要求手写链表或资源管理时保留该训练目标。
- 区分值、引用、指针、`const` 限定的位置和复制成本。`std::move` 是转换，不保证一定执行移动，也不能把所有移动后的对象说成“空”或“一律不可用”。
- 涉及通过基类指针删除派生对象时，核对析构函数与适用规则。区分重载、覆盖和名字隐藏；不要只因函数同名就判为多态。
- 排序比较器检查严格弱序，不能用 `<=` 替代 `<`。二分搜索检查有序或分区前提。混用有符号下标和无符号 `size()` 时先分析实际取值。

## Java

- 区分基本类型值和引用值。Java 始终按值传递；对象参数复制的是引用值，修改对象与重绑定形参是两件事。
- 引用类型的 `==` 判断引用是否相同；逻辑相等取决于 `equals` 的实现。`String.equals` 比较内容；数组内容比较通常需 `Arrays.equals` 或合适的深度比较。不能把任意对象的 `equals` 都说成按字段比较。
- 检查 `equals` / `hashCode` 的一致性、可变对象作为哈希键、泛型边界、拆箱空指针和集合的真实元素类型。包装类型缓存不能作为业务相等判断依据。
- 普通 `int` / `long` 整数算术溢出不会自动抛异常；赋给 `long` 前可能已经发生 `int` 运算溢出。区分整除、浮点除法和特殊边界；需要检测溢出时按任务考虑精确运算 API。
- 区分重载的编译期选择和覆盖的动态派发，检查异常路径、资源关闭、数组边界和 `null`。`Scanner` 混用读数与读行时检查剩余行尾。
- 类、包、文件名和入口的合法性按目标 JDK 及课程/OJ 要求判断，不能把传统 `public static void main(String[] args)` 当成所有 Java 版本唯一的合法入口形式。

语义核对入口：[Java 语言规范第 15 章（SE 25 示例）](https://docs.oracle.com/javase/specs/jls/se25/html/jls-15.html)；入口形式参见[第 12.1.4 节](https://docs.oracle.com/javase/specs/jls/se25/html/jls-12.html#jls-12.1.4)。不同课程使用对应版本，不把此链接的版本当成默认要求。

## Python

- 对象共享：可变默认参数在函数定义时创建；`[[0] * m] * n` 共享内层列表；浅拷贝保留嵌套对象引用。分别追踪“名字绑定”和“对象修改”。共享也可能是有意设计，需结合需求判错。
- `is` 判断身份，`==` 判断相等；不要凭小整数或字符串驻留现象推导普遍规则。判断 `None` 通常使用 `is None`。
- 检查闭包迟绑定、局部赋值导致的作用域问题、循环中修改容器、迭代器被消耗、切片端点、空序列和负索引的合法含义。
- `list.sort()` 原地修改并返回 `None`，`sorted()` 创建排序结果；`append` 与 `extend` 的效果不同。不要把 `result = items.sort()` 当成返回已排序列表。
- Python 整数除法 `//` 向下取整，`/` 为真除法；内建整数不按固定 32 位回绕，但受可用资源限制。浮点值并非任意精度实数。
- Python 没有 Java/C++ 式按签名自动选择多个同名函数的机制；后一次同名定义通常覆盖前一次绑定。类型标注通常不会自动实施运行时类型检查。
- 复杂度分析注意切片、列表成员查询、重复字符串拼接、列表头部删除等实际成本；不要只数循环嵌套层数。

语义与常见误区入口：[Python 官方编程 FAQ](https://docs.python.org/3/faq/programming.html)。需精确版本行为时选对应版本文档。

## 比较时必须说清的差异

| 概念 | C / C++ | Java | Python |
| --- | --- | --- | --- |
| 整数除法的负数方向 | C99 起及 C++11 起，整数 `/` 向零截断 | 整数 `/` 向零截断 | 整数 `//` 向下取整 |
| 参数传递 | C 按值，可传指针；C++ 还支持引用形参 | 按值，可能传引用值 | 传入对象供形参绑定，通常称对象共享传递 |
| 相等与身份 | 按具体类型及重载；C 字符数组不能用 `==` 比内容 | 引用 `==` 与 `equals` 分开 | `is` 与 `==` 分开，类可定制相等 |
| 生命周期 | C 需区分存储期与动态内存；C++ 还有析构和 RAII | 垃圾回收管理内存，外部资源仍需管理 | 自动内存管理；资源宜用上下文管理，不依赖特定回收时机 |
| 下标越界 | 内建数组无通用自动边界保护；C++ 容器取决于访问 API | 数组及常用集合有相应越界检查 | 序列元素访问通常抛 `IndexError`，切片允许截断 |

比较除法应排除零除数和各语言特殊溢出边界，例如 C/C++ 的最小有符号整数除以 -1，不能只凭表格机械推算所有输入。
